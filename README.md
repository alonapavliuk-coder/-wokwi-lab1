Arduino UNO
Проєкт демонструє базові принципи підключення та програмного керування зовнішніми компонентами мікроконтролера. У межах роботи в симуляторі зібрано електричну схему зі світлодіодом і захисним резистором, підключену до цифрового піна плати, та реалізовано програму циклічного миготіння («Blink») для перевірки коректності роботи системи.
Посилання на проект: https://wokwi.com/projects/480876053015830529 .
